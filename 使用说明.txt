TX DESK · 本机交易风控工具

怎么用
1. 双击「启动.command」（Mac）或「启动.bat」（Windows），浏览器会打开本机页面。
   也可以把 index.html 直接拖进 Chrome / Safari / Edge。
2. 拖入一份当天的交易记录 .xlsx（一次一个文件）。优先读工作表「数据」，没有则读第一张表。可先用上一级目录里的「交易记录-127.xlsx」试跑。
3. 看总览 / 异常台账 / 通道账户 / 用户 / 单卡 / 群充 / MCC。
4. 点「导出 PDF」：打印对话框里选「存储为 PDF」，勾选「背景图形」，纸张建议横向。
   打印时会展开全部页签（不是只打当前页）。

数据不出本机。内部看 HTML；外发只发 PDF。卡号一律掩码。

口径（写死，阈值可在「高级选项」改）
- 拒付 = 交易失败。消费拒付率 = 消费失败笔 / 全部消费笔（含已取消、待处理，不去掉）。
- 退款仅交易类型=退款。已取消正金额不算退款。
- 跨日退款：该卡在退款当日无成功消费 → 放入滚动窗口，不进当天退款比，不用当天成功消费当分母。当天退款比只计「该卡当日有成功消费」的退款。
- 金额用「金额」绝对值，按账户币种折 USD。默认 EURUSD 1.1579、USDINR 95.61。USD 账户的 PHP/TWD 不再折。
- 小额：折美元后 abs < $30。
- 广告：FACEBOOK / META / TIKTOK / FACEBK，以及商户名含 ADS 的 Google。Google One / YouTube / EA Sports / GOOGLE*CHATGPT 算订阅。
- 主键：通道 × 帐户名。default 会跨多个通道。
- 单卡转入：次数 >3 且相邻间隔 <120 秒 → 双规则命中。另分「仅次数」「仅快充」表。
- 群充：同一用户转入相邻 <120 秒为一簇，簇内卡数 ≥2。与单卡分开记账。

后期改规则 / 加规则
- 阈值与汇率：页面「高级选项」，改完立刻重算。
- 分类与新规则：编辑 js/rules.js（isAds / mccCluster / failBucket / RULE_DEFS）。
- 新规则的表格：在 js/render.js 补视图。需要全新指标时把函数推进 TX.extraRules。
